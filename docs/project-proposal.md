# Project Proposal

## Project title
Development of an Intelligent Kanban System with an AI Assistant for Automatic Task Generation from Voice Messages

## Team
- Akbope Bakytkeldy | SE-2426
- Symbat Saparbay | SE-2424

## Problem
Team members often discuss work in voice messages. Turning those messages into tasks manually takes time, and important details can be missed

## Target users
Small project teams that use voice messages to discuss and assign work

## Aim
Develop a system that suggests a Kanban task from a voice message and adds it to the board after the user reviews and confirms it

## Main user scenario
1. A user sends a voice message
2. The system converts the voice message to text
3. The system suggests a task title, assignee, and deadline when these details are present
4. The user reviews and edits the suggested task
5. The user confirms it, and the task appears on the Kanban board

## First-version scope
- Process one task from one voice message
- Show the suggested task for review
- Let the user edit and confirm it
- Add the confirmed task to a Kanban board

## Outside the first-version scope
- Automatically adding tasks without user confirmation
- Processing several tasks from one voice message.
