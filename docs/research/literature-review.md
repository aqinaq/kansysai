# Literature Review

## Project Title
Development of an Intelligent Kanban System with an AI Assistant
for Automatic Task Generation from Voice Messages

## 1. Introduction

Traditional task management systems require users to create
tasks manually, add descriptions and deadlines.

Our project is aimed at the development of an intelligent Kanban
system that automatically extracts structured tasks from voice
messages using Artificial Intelligence (AI).

Such system integrates technologies of speech recognition,
natural language processing and task management. Users have the
opportunity to record voice messages, see the extracted details of
the task and confirm its creation.

## 2. Research Objectives

The literature review includes the following topics:

1. Speech-to-Text technologies.
2. Natural Language Processing and Large Language Models.
3. Structured task extraction and data validation.
4. Integration of AI with Kanban systems.
5. Speech recognition and task extraction evaluation.
